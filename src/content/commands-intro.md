The server's own commands for the YAGPDB.xyz bot. Most are slash commands: type `/` in a
channel and Discord offers the bot's commands as you type — pick one and fill in its fields.
A few aren't typed at all: their entries show the message that fires them instead (a `#`
color code, a channel mention, a 👍). And two — `/hugemoji` and `/avatar_viewer` — are still
typed as ordinary messages: Discord's list has no match for them, so your message goes
through as you typed it and the bot answers. Most commands work in any channel, but please
use the Bots channels for them.

In the examples, `<text>` is something you fill in and `[size]` something you can leave out.
A command like `/hebrew` that groups several tools shows one example line per tool.
